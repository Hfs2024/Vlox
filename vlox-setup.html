The Vlox Setup Handbook

Deploy Your Own Social Platform in 15 Minutes

Chapter 1: What is Vlox?

Vlox is a complete, open-source social media platform built from the ground up for simplicity and performance. It features user authentication, comments, reactions (likes/reports), a unique card generator and more. It uses my custom DOM library, NanoScript, on the frontend and a powerful Node.js/Express/MongoDB stack on the backend.

Note: To clone the repository, you will need a GitHub account (it's free to create). If you don't have one, you can sign up at github.com before you begin. Alternatively, you can skip the account and download the ZIP file directly using Option 2.

Why You'd Want It:

  • You get a fully functional social network in a box.
  • It is built to be simple and easy to customize.
  • It uses a modern, efficient tech stack.
  • You own your data and your community.

Chapter 2: Prerequisites

Before you start, make sure you have these installed on your computer:

  • Node.js (v16 or higher)
  • Git or GitHub Account (to clone the repository)
  • MongoDB Compass (to set up and view your database)
  • A text editor (like VS Code)

Chapter 3: Installing Node.js (If You Don't Have It)

Node.js is the runtime that runs Vlox. If you don't have it installed:

  1. Go to nodejs.org.
  2. Download the LTS (Long-Term Support) version (the one recommended for most users).
  3. Run the installer and follow the default steps.
  4. To verify it is installed, open your terminal and run:
   node -v

You should see a version number like v16.x.x or higher.

Chapter 4: Getting the Code

Option 1: Clone the repository (Recommended)

Open your terminal, then run this command:

git clone https://github.com/Hfs2024/Vlox.git

Enter the project folder:

cd Vlox

Option 2: Download as a ZIP (Alternative)

  1. Go to the Vlox GitHub page: https://github.com/Hfs2024/Vlox.

  2. Click the green "Code" button, then "Download ZIP".

  3. Extract the ZIP file and open that folder in your terminal.

Chapter 5: Installing Dependencies

Once inside the Vlox folder, run this command to install all the necessary libraries:

npm install

This will install Express, Mongoose, and all other dependencies.

Chapter 6: Setting Up MongoDB (Your Database)

You need a database to store users, posts, and comments. Here is the simplest way to set it up locally:

Download and Install MongoDB Compass. This is a visual tool to manage your database.

  1. Open MongoDB Compass. Click the "New Connection" button.
  2. Name Your Connection. You can call it Vlox-Database as an example.
  3. Save and Connect. Just click the "Save & Connect" button. Compass will use the default local settings.
  4. Get Your Connection String. After connecting, Compass will show you a string that looks like mongodb://localhost:27017. This is your MONGO_URI.

Note: You can also use your MongoDB Atlas cloud connection string here

Chapter 7: Setting Up Your Environment Variables (.env File)

This file keeps your configuration safe.

In the Vlox folder, create a new file and name it exactly: .env

Open that file in a text editor and paste in the following template:

PORT=3000
MONGO_URI=your_mongodb_connection_string
SESSION_SECRET=your_super_secret_key
# Change this to production when deploying
NODE_ENV=development

Now, fill in the values:

  • PORT: You can leave this as 3000.
  • MONGO_URI: Paste the connection string you got from Compass (mongodb://localhost:27017).
  • SESSION_SECRET: This is for security. Type a long, random string of letters and numbers (e.g., aF3d8G7hJ9kL2zX1cVbN5mQwE6rT4yU).
  • NODE_ENV: Leave this as development for testing.

Chapter 8: Running Your Vlox Server

You are now ready to start your platform!

In your terminal (inside the Vlox folder), run this command:

npm start

or

node server.js

If everything is set up correctly, you will see this message in your terminal: 

Clean Engine live on port 3000
MongoDB connected

Final Step: Open your web browser and go to http://localhost:3000. Your Vlox instance is now live! You can sign up and start using it immediately.

Chapter 9: Next Steps & Customization

Congratulations! You have successfully deployed Vlox.

You can now:

  • Explore the Code: Look at server.js for backend logic and schemas.js for the database structure.

  • Customize the Look: Edit the CSS files in the public folder.

  • Add Features: Vlox is modular. You can easily add new routes and frontend features

  • Learn NanoScript: Vlox uses my custom library. It is lightweight, jQuery-like and easy to learn. You can find more info on the GitHub repo at https://github.com/Hfs2024/NanoScript.

Where can you host it?

You can host your application for free on several modern cloud platforms:

  • Bonto: Currently used at https://vlox.bonto.run and excellent because it perfectly supports your Vlox's architecture at no cost.
  • Render: Offers a free tier for web services, though it may require a credit card verification to activate.

Note: You should avoid Vercel, Netlify, or any other serverless hosting service because Vlox is not compatible with serverless architecture.
