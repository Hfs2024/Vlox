# Vlox

Vlox is my social media platform built to connect people.

## How I Built Vlox

Hey guys! 👋🏻

I'm Seif, a 13yo self-taught software engineer. My journey into real full-stack development began when I tried to create my first production project: **PixUp**. PixUp was my private social media platform I built with Vanilla JavaScript. Its codebase quickly became messy and unmaintainable, so I abandoned it last year. 

I didn't stop after one failure. In early 2026, I started creating another social media platform: **BlockSocial**. I added complex features like JSONL exports, backup uploads, and post forks. It rapidly grew into a complex system that was difficult for me to maintain alone. 

I had to stop and ask myself: *Why do my social media apps keep failing?* The answer was always the same: **Verbose Vanilla JS.**

## The Problem & The Solution

When planning my next platform, **Vlox**, I looked my frontend options:

* **jQuery?** Too outdated.
* **Modern Frameworks (React/Vue)?** Too heavy.
* **Vanilla JS?** Too verbose.

Since I have no plans to turn Vlox into a massive enterprise application, heavy frameworks felt like overkill. To keep the project lightweight while avoiding verbose native code, I chose Cash for fast, simple DOM manipulation. I also chose Cash over heavy frameworks to prove a really important point: You don't need the traditional tools to build something clean, working and safe.

## Bringing Vlox to Life

With Cash keeping the frontend lean and efficient, I successfully built Vlox as a clean MVP. 

### Core Tech Stack
* **Frontend:** Cash 
* **Backend:** Node.js & Express
* **Database:** MongoDB

Thanks to this architecture, the frontend is finally at a point where I can easily make updates without running into messy code.
