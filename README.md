# Vlox

Vlox is my social media platform built to connect people.

## How I Built Vlox

I'm an experienced web developer, and my journey into full-stack development began when I tried to build **PixUp**, a private social media platform. I built it with Vanilla JavaScript. Soon, the codebase quickly became bloated, messy, and unmaintainable. 

A few months later, I started **BlockSocial**. I added complex features like JSONL exports, backup uploads, and post forks. It rapidly grew into a complex system that was difficult for me to maintain. 

I had to stop and ask myself: *Why do my social media apps keep failing?* The answer was always the same: **Verbose Vanilla JS.**

## The Problem & The Solution

When planning my next platform, **Vlox**, I evaluated my frontend options:
* **jQuery?** Too outdated.
* **Modern Frameworks (React/Vue)?** Too heavy.
* **Vanilla JS?** Too verbose.

Since I have no plans to turn Vlox into a massive enterprise application, heavy frameworks felt like overkill. To keep the project lightweight while avoiding verbose native code, I chose Cash for fast, simple DOM manipulation.

## Bringing Vlox to Life

With Cash keeping the frontend lean and efficient, I successfully built Vlox as a clean MVP. 

### Core Tech Stack
* **Frontend:** Cash 
* **Backend:** Node.js & Express
* **Database:** MongoDB

Thanks to this architecture, the frontend is finally at a point where I can easily make updates without running into messy code.
